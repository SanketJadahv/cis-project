Fundamental Cryptographic Principles

Core theoretical pillars demonstrated by this interactive system.

01

Kerckhoffs's Principle

A cryptographic system should remain secure even if everything about the algorithm is public knowledge. Security must rely solely on keeping the key secret. Modern algorithms like AES-256 are completely open source and public, yet mathematically unbreakable when strong random keys are used.

02

AEAD: Confidentiality + Integrity

Encryption alone (confidentiality) does not prevent an attacker from modifying or tampering with ciphertext in transit. AES-GCM (Authenticated Encryption with Associated Data) computes a 16-byte authentication tag that immediately exposes any unauthorized modification, bit-flip, or falsification.

03

Nonce Uniqueness (Never Reuse)

The Number used ONCE (Nonce / IV) ensures that encrypting identical messages multiple times yields completely unpredictable and unique ciphertexts. In AES-GCM, reusing a Nonce with the same key catastrophically compromises the authentication tag and can reveal plaintext information.
